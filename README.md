# Eagle Innovia Ltd — website

Source for https://www.eagleinnovia.com. Built with Astro and Tailwind CSS, hosted on GitHub Pages.
Every push to `main` builds and deploys automatically (`.github/workflows/deploy.yml`).

- Site-wide details and placeholders: `src/config/site.ts`
- Page content: `src/content/` (services, programmes, products, case studies)
- Local development: `pnpm install` then `pnpm dev` (Node 24)
