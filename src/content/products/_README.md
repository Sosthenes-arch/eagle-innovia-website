# Products

Add one Markdown file per product here (files starting with `_` are ignored).
Product cards appear on /naturals (line: naturals) and /products (line: digital) automatically.

```md
---
title: Cloud Career Starter Ebook
line: digital            # naturals | digital
kind: Ebook              # e.g. Ebook, Template, Course, Workbook, Hair oil
description: One or two sentences about what the buyer gets.
price: ₦5,000            # optional
link: https://selar.co/your-product
platform: Selar          # Selar | Amazon
image: ../../assets/products/cloud-career-ebook.jpg   # optional
imageAlt: Cover of the Cloud Career Starter ebook     # required if image is set
---
```
